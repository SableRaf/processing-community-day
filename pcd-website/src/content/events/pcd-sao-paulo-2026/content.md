1. Introduction to Creative Coding with Processing
Brief Description
An introductory workshop for artists, students, and curious beginners who want to explore creative coding through Processing (Java). Participants will be introduced to the basics of programming in a visual and accessible way, learning how code can be used as a creative medium for graphics, animation, interaction, and artistic experimentation.
The workshop will present the Processing IDE, fundamental programming structures, and practical examples developed live during the session. Participants will also be introduced to the wide ecosystem of open-source resources, libraries, and online communities that support creative coding practices.
Duration: 1 hour
Target Audience: Beginners, artists, students, and anyone curious about creative coding.
Project Description / Program Content
Introduction to creative coding and artistic applications
Overview of the Processing IDE
Basic structure of a Processing sketch
Variables, functions, loops, and interaction fundamentals
Development of simple visual examples in real time
Introduction to animation
Overview of useful libraries and online resources
References to creative coding communities and projects
Q&A and discussion


2. Video Mapping for Performing Arts with Luna Mapping Library
Brief Description
This workshop introduces the use of the Luna Video Mapping Library for Processing, focusing on practical applications in theater and dance performances. Participants will learn how projection mapping can become an accessible creative tool for scenic composition, spatial transformation, and live visual experimentation.
The workshop is designed for performing artists with no prior coding experience required. Through demonstrations and practical examples, participants will explore how video mapping can interact with performers, objects, and stage environments using accessible workflows and open-source tools.
Duration: 1.5 hours
Target Audience: Theater makers, dancers, performers, directors, stage designers, and visual artists interested in projection mapping.
Project Description / Program Content
Introduction to projection mapping in performing arts
Overview of the Luna Mapping Library
Basic setup for projection mapping using Processing
Mapping surfaces and stage elements
Organizing visual scenes and compositions
Working with video, images, and generative visuals
Practical examples for theater and dance applications
Discussion about technical setup and creative possibilities
Q&A and experimentation session


3. Interactive Visuals in Theater and Dance: Experimentation Lab
Brief Description
An experimental laboratory focused on the creative and technical challenges of integrating interactive visuals into theater and dance performances. Rather than offering fixed solutions, the workshop proposes a shared space for experimentation, discussion, and collaborative exploration.
Participants will be introduced to fundamental concepts behind interactive systems, including real-time visual response, performer interaction, spatial relationships, and technological limitations within live performance contexts. The workshop aims to open pathways for future research and artistic development.
The activity welcomes both performing artists and technologists interested in interdisciplinary collaboration.
Duration: 1.5 hours
Target Audience: Performing artists, creative technologists, designers, researchers, and interdisciplinary creators.
Project Description / Program Content
Introduction to interactive visuals in live performance
Examples and case studies from theater and dance
Discussion of artistic and technical challenges
Real-time interaction concepts and workflows
Sensors, cameras, tracking, and responsive systems overview
Spatial relationships between performers, visuals, and audience
Collaborative experimentation exercises
Exchange of references, methodologies, and experiences
Open discussion about future possibilities and research paths
