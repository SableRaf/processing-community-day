Join us for a **full day of creative coding** at Processing Community Day in
Markdorf! This description exists to exercise _every_ supported markdown
feature (except images).

## What to expect

We'll spend the day exploring Processing and p5.js together, from your *very
first sketch* to more ambitious generative work. Everyone is welcome —
beginners especially.

### Schedule highlights

1. Welcome & setup
2. Beginner introduction to **p5.js**
3. Hands-on workshop: *generative patterns*
4. Lightning talks and show-and-tell

Bring along:

- A laptop (any OS works)
- Your curiosity
- An optional project you'd like to share
- ~~Prior experience~~ — not required!

## Resources

Sign up via [our forum thread](https://discourse.processing.org/) or just show
up. You can also visit <https://processing.org> to learn more beforehand.

You can start a sketch in one line of code:

```js
function setup() {
  createCanvas(400, 400);
}
```

Inline code works too: call `noLoop()` to stop the draw loop.
